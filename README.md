# Teko News Hub

A full-stack News Portal website where users can read, publish, edit, and delete news. Built with the MERN stack and deployed on Vercel and Render.

## 🚀 Live Demo
- **Frontend:** [https://teko-news-hub.vercel.app](https://teko-news-hub.vercel.app)
- **Backend API:** [https://teko-news-backend.onrender.com](https://teko-news-backend.onrender.com)

*(Note: The backend is hosted on Render's free tier, so it may take up to 50 seconds to spin up on the first request after periods of inactivity.)*

## ✨ Features
- **Home Page:** 4-5 sections including Top 6 News, Categories, and Recent News.
- **All News Page:** Browse all news with search and category filters.
- **Single News Details:** Read full articles, track views, and view author details.
- **Authentication:** Secure Login and Registration using JWT.
- **Publish News:** Registered users can create and publish their own news articles.
- **User Dashboard:** Users can update their profile info.
- **Edit & Delete:** Users can edit or delete their own published news.
- **Contact Us:** A responsive contact form.
- **Responsive Design:** Fully responsive UI built with Tailwind CSS.

## 🛠️ Technologies Used
- **Frontend:** React.js, Vite, Tailwind CSS, Zustand (State Management), React Router DOM, Axios, React Icons, React Hot Toast.
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Bcrypt.js.
- **Deployment:** Vercel (Frontend), Render (Backend), MongoDB Atlas (Database).
